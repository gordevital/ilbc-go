# iLBC for Go (RFC 3951 port)

A Go port of the Internet Low Bit Rate Codec (iLBC) as specified in RFC 3951.

## Status

The fixed-point engine (`internal/ilbcfix`) is bit-exact against the C
reference (WebRTC `libilbc`): during development a comparison suite drove
the Go and C implementations with identical signals and loss patterns and
compared payloads and decoded PCM element-wise; the committed golden
fixtures freeze that agreement for regression. The public facade and the
`cmd/` tools run on this engine.

### Implemented

- Public facade (`ilbc.Encoder`, `ilbc.Decoder`) with idiomatic Go API,
  backed by the fixed-point engine.
- Fixed-point codec core `internal/ilbcfix` mirroring the C reference
  structure (instance layouts, Q-domains, `WEBRTC_SPL_*` primitives).
- Frame classification, start-state selection, codebook search, decoder
  synthesis, packet loss concealment, spectral enhancement.
- SRTP/SRTCP AEAD AES-GCM profiles (`internal/srtp`): AES-128-GCM and
  AES-256-GCM with 16-octet tags, byte-compatible with libsrtp 2.5.0
  (legacy ICM KDF, SRTP 3711-style nonce construction). Verified against
  golden vectors in `internal/srtp/testdata/vectors_gcm.txt`, regenerable
  via `tools/srtpvectors/build_vectors.sh`.
  The CLI tools speak it end-to-end: `ilbcwav2rtp -key HEX -salt HEX`
  protects the stream, `ilbcrtp2wav -key HEX -salt HEX` unprotects it
  (the 20/30-ms frame length is recovered by authentication).
- Plain RTP/RTCP framing helpers (`internal/rtputil`).

### Constant tables

Exact integer tables in their original C Q-domains live in
`internal/ilbcfix` (generated by `tools/gen_tables.py` from WebRTC
`libilbc/modules/audio_coding/codecs/ilbc/constants.c` and verified
element-wise against it). Golden encode/decode fixtures for regression
tests sit in `internal/ilbcfix/testdata/fixtures/`; the input signals are
deterministic and reproducible via `tools/genfixtures`, the golden outputs
are frozen records of the reference behaviour.

### Known gaps

- No VAD/comfort-noise extensions beyond the base codec.

## Usage

```go
enc, _ := ilbc.NewEncoder(ilbc.Mode30ms)
dec, _ := ilbc.NewDecoder(ilbc.Mode30ms)

payload, _ := enc.Encode(pcm160)   // []int16, 160 or 240 samples
pcmOut, _  := dec.Decode(payload)  // 160 or 240 samples
```

For packet loss concealment call `dec.Conceal()` when a packet is missing.

CLI helpers live in `cmd/` (`ilbcwav2rtp`, `ilbcrtp2wav`, `ilbcgenspeech`).

## Build & test

```
go build ./...
go test ./...
```

## Layout

```
ilbc/              public facade (modes, Encoder, Decoder, errors)
internal/ilbcfix/  fixed-point codec core (bit-exact vs C reference)
internal/wavio/    WAV R/W helper for the cmd/ tools
internal/cliflags/ shared CLI flag parsing
internal/srtp/     SRTP/SRTCP AEAD AES-GCM (byte-compatible with libsrtp 2.5.0)
internal/rtputil/  plain RTP/RTCP packet framing
cmd/               console utilities (ilbcwav2rtp, ilbcrtp2wav, ilbcgenspeech)
examples/          runnable examples (roundtrip)
tools/             fixture and SRTP-vector generators
```
